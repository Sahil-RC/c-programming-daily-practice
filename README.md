## ⚙️ How to Compile and Run a C Program

Follow these steps to compile and execute a C program.

### Step 1: Write the C Program

Write your C program in **Visual Studio Code** and save the file with the `.c` extension.

Example:

```c
#include <stdio.h>

int main() {
    printf("Hello, World!");

    return 0;
}
```

Save the file as:

```text
hello.c
```

### Step 2: Open the Terminal

Open the terminal in Visual Studio Code or open Command Prompt / PowerShell.

### Step 3: Navigate to the Program Directory

Use the `cd` command to move to the folder where your C program is saved.

```bash
cd file_path
```

Example:

```bash
cd C:\Users\Sahil\Documents\C-Programming
```

### Step 4: Compile the C Program

Compile the program using the `gcc` compiler:

```bash
gcc hello.c -o hello
```

Here:

* `gcc` → C compiler
* `hello.c` → C source file
* `-o hello` → Creates an executable file named `hello`

### Step 5: Run the Program

On Windows, run the compiled program using:

```bash
.\hello
```

On Linux or macOS, use:

```bash
./hello
```

### Step 6: View the Output

After running the program, the output will be displayed in the terminal.

Example:

```text
Hello, World!
```

## 🔄 Program Execution Flow

The basic process of executing a C program is:

```text
Write C Program
      ↓
Save File with .c Extension
      ↓
Open Terminal
      ↓
Navigate to Program Folder
      ↓
Compile Using GCC
      ↓
Create Executable File
      ↓
Run the Executable
      ↓
View Output
```
